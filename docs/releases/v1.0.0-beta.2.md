A small update to the first beta of **Aetheria**.

**[▶ Play in your browser](https://heavenly3.github.io/Aetheria/)** or **[on itch.io](https://3vynia.itch.io/aetheria)**.

## Fixes

- Character creation now fits phone screens: the step bar no longer pushes the form off the sides of the screen, and only the current step shows its name on narrow screens.

## Downloads

- `aetheria-web-v1.0.0-beta.2.zip`: the web build. Unzip it on any static host or upload it to itch.io as an HTML game.
- `aetheria-v1.0.0-beta.2.html`: the whole game in one file. Download it and open it in a browser, no internet needed.

Saves from beta 1 keep working.
